# Tekstury (CC0)

Zdjęcia powierzchni z [Poly Haven](https://polyhaven.com) na licencji CC0, wersje 1k JPG
(kolor + mapa normalnych OpenGL). Używa ich shader świata (`shaders/world.gdshaderinc`)
jako tekstur trójplanarnych.

| Plik | Zasób Poly Haven | Zastosowanie |
|---|---|---|
| `sand_01_*` | sand_01 | piasek, wydmy |
| `rock_face_03_*` | rock_face_03 | skały, ściany kanionu |
| `asphalt_03_*` | asphalt_03 | droga |
| `rusty_metal_02_*` | rusty_metal_02 | rdza i brud na pojazdach, wrakach, rekwizytach |
